Automotive Order Management

About the Application

Automotive Order Management is an application designed to manage customer orders for a European automotive retail company.

Authorized users can create orders, calculate totals including 21% VAT, and consult previously saved orders.

1. User Authentication

Open the login page and enter your username and password. Both fields are required.

Successful authentication provides access to the operations menu.

2. Create a New Order

  1. Open the operations menu.
  2. Select Create New Order.
  3. Enter a unique order ID.
  4. Enter the customer's required information.
  5. Select at least one automotive product.
  6. Enter a positive quantity for each selected product.
  7. Click Save Order.

The server validates the information, calculates the total including 21% VAT, and stores the order in the orders file.

3. View Orders

Select View Orders from the operations menu.

View All Orders

Choose View All Orders to display every previously saved order.

View One Order

Choose View One Order, enter an order ID, and submit the query to display its details.

4. Error Messages

The application reports invalid input, duplicate order identifiers, missing orders, and authentication errors.

5. Logout

Use the Logout button from the operations menu to end the current session.
