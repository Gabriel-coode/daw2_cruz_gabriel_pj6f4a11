# Automotive Order Management App

## Description

This is a web application for managing customer orders in an automotive store.

## Features

- User authentication.
- Create new orders.
- View all orders.
- Search for an order by its ID.
- Calculate order prices with 21% VAT.

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- JSON
- Apache (XAMPP)
- Git and GitHub

Project in development.
